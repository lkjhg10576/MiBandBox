# 净室实现说明

## 隔离墙

| 规则 | 落实 |
|---|---|
| 不复制源码 | 原包只有 `.jsc` 字节码；交付物不含任何反编译产物或 `.rpk` |
| 不复制资源 | 26 个应用图标、公共图、应用图标全部由 `tools/gen-assets/gen.py` 自绘 |
| 不复制文案/数据 | 每日一言、答案之书、史载今日、垃圾分类、饮食池全部自写/自建 |
| 只依据行为规格 | 页面结构按 `REPORT.md` 的行为描述重写；API 使用 Vela 官方文档 |
| 不冒用身份 | 包名 `com.cleanroom.bandbox`，名称 BandBox；无 `charlie` / `Hyper Box` / `AstroBox` 字样 |

## 付费/授权系统删除清单

- `pages/activation/*`（6 页）
- 首页与设置页的激活拦截、`bannedDevices` 机型白名单
- 木鱼 Pro 标识与 `fish/ab` 下载诱导页
- `lyrics/choose` 的第三方扫码引流
- `push` 的厂商互传协议（改为本地导出/二维码/跑马灯）
- 内置 Xiaomi 圆体字体（改为 OFL 字体子集）

## 数据来源

| 数据 | 来源 | 规模 |
|---|---|---|
| 每日一言 | 自撰 | 100 条 |
| 答案之书 | 自撰 | 100 条 |
| 史载今日 | 公共领域科技文化事实，措辞自写 | 90+ 日期 + 12 条小知识 |
| 垃圾分类 | 公开分类常识，词表自建 | 200+ 物品 |
| 饮食 | 通用食物/饮品名 | 60 条 |
| 摩斯 | ITU 基本表 | 字母/数字/符号 |
| 性能参考分 | 公开参数与自测估算 | 11 机型 |

## 验收自检
