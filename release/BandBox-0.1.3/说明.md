# BandBox 0.1.3 构建产物

构建时间：2026-11-26（本地）

- 手环端：`com.lkjhg.bandbox` **0.1.3**（`versionCode` 295，jsc 字节码版）
- 手机插件：`BandBox辅助` **0.1.3**（源码现编，与仓库源码一致）

> **production 打包**：由 `aiot release` 构建 —— JS 已压缩混淆、已剔除 `.map`、签名用发行证书。包名始终是 `com.lkjhg.bandbox`，文件名里的 `.release.` 段只表示打包模式，不是 debug 包。

> **本版定位**：`0.1.2`（三机型首个正式发行版）之后的首个功能版本。四条主线：① 新工具「**时区换算**」，工具总数 40 → **41**；② 首页「**长按工具管理**」（置顶 / 收藏 / 隐藏）与 Pro 专属「**双栏网格**」；③ 桌面伴侣「**精美样式**」位图遮罩数字、字号与图标全面加大；④ **冷启动与内存治理** —— 协议栈移出启动路径、KV / 互联层 / OTP 缓存收口、新增门禁 R20。
>
> 手环端快应用与手机插件同号（均为 `0.1.3`）。本版是 **production 打包**（JS 压缩混淆、剔除 `.map`、自签发行证书签名），可对外分发。

## 一、新工具：时区换算

- **246 个城市**（覆盖各国首都与跨多时区国家），15 个热门城市置顶。
- **自动夏令时**：内置 8 类 DST 规则（美加 / 欧盟 / 澳大利亚 / 新西兰 / 智利 / 以色列 / 埃及 / 古巴），按换算时刻实时判定，UTC 标签与「夏令时」标记同步显示。
- **24 小时时间输入**：复用统一数字键盘页 `pages/numinput`（新增 `type: 'time'`），冒号键、前导零保留、时分范围校验（0–23 / 00–59）都在键盘页内完成，不弹系统输入法。
- **城市检索**：支持中文城市名 / 国家名、拼音全拼与首字母、英文名、`UTC+8` / `GMT-5` 偏移检索；空查询显示热门城市。
- **换算结果**：来源 / 目标双栏卡片，显示双方 UTC 偏移、跨日标签（昨天 / 今天 / 明天 / 前天 / 后天）与中文时差描述；支持「交换」与「现在」，上次选择的城市对持久化。
- 纯 JS 引擎 `src/utils/timezone.js` 零 `@system.*` 依赖，Node 单测 11 项覆盖 DST 边界、检索与键盘状态机。

## 二、首页与工具管理

- **长按工具管理**：任意首页布局下长按工具条目进入「功能设置」页（`pages/toolact`）。
  - **置顶**上限 4 个，按操作先后排在首页最上方；**收藏**无上限，首页在置顶区之后出现「收藏功能」入口（`pages/toolfav`）；**隐藏**的工具在首页与分类详情页都不显示，管理入口在「设置 → 隐藏功能」（`pages/toolhide`）。
  - 隐藏一个已置顶 / 已收藏的工具时，数据层统一把它移出置顶与收藏，不留残影。
  - 置顶 / 收藏卡改为与设置页「工具分类」同款开关（整卡可点、蓝底 + 「开/关」），隐藏卡保持危险操作样式。
  - 长按抬手后系统补发的 click 用 800ms 守卫挡掉，不会误进工具页。
- **Pro 专属「双栏网格」**：首页样式页在网格不是两列的机型（Pro）多出「双栏」选项，卡片 159×76、每行恰好两格；band10 / band9 的网格本就是两列，选项自动隐藏，页面与改前逐像素一致。
- **工具分类模式补全**：分类详情页同样支持长按管理；全隐藏的分类保留并显示「0 个工具」；置顶工具在分类模式里以单栏条目在首页顶部显示，同时保留原分类归属（双显示口径）。

## 三、桌面伴侣「精美样式」

- 第三版式改为**表盘风**：左侧一整行自绘数字时间（固定 HH:MM），右侧信息列（周几 + 几号 / 目标日倒计时 / 分隔线 / 电量徽标）。
- **字形改用反相遮罩位图**（`fdm_0..9.png`）：每位数字 = 黑底容器 + 彩色底 + 全铺遮罩，任意 `#RRGGBB` 取色都生效并保留抗锯齿边缘；10 张遮罩在 rpk 里仅 19,214 B，比旧彩色位图省 38%。
  - 数字按各自墨迹宽紧排（「1」比「0」窄），不是定宽格；只缩不放，Pro 最大字高 190。
  - 彩色底相对容器左 / 右 / 下各内缩 1px，兜住真机远边半纹素采样污染，消除数字右缘与底缘的 1px 彩线。
  - 遮罩未全部就绪前容器保持黑底，避免先闪出彩色方块。
- **整分刷新**：精美样式与关秒模式走「对齐下个整分 +20ms」的定时器，长亮时每小时只重绘 60 次，不再每秒刷新。
- 新增**取色板页** `pages/colorpick`（预设色 + 自定义），供精美样式选择数字颜色。
- 修复 Band 9 上数字左缘的 1px 半透细线，以及无目标日时日期与电量之间的多余间隙。

## 四、字号与图标

- **字号硬底线 14px**（新增门禁 **R18** 拦截）：提示 / 副标题优先 15px，高频面整体抬高 —— 首页网格标签 18px、列表 / 分类 / 收藏 / 隐藏行名称 19px、页头标题 18px、设置卡标题 18px / 副题 15px。
- **文字色三档**：主 `#FFFFFF`、次 `rgba(255,255,255,0.72)`、提示 `rgba(255,255,255,0.55)`；正文 / 提示不得低于 0.55（R19 对更低透明度出提醒）。
- **34 个图标重做**：44×44 RGBA8、4× 超采样 + LANCZOS、主描边 6px / 最小 4px，近白 `#E8EEFF` 主色 + 蓝 `#4E87FF` 点缀；首页按 32×32 显示，列表行 34×34，只缩不放。
- **桌面图标改圆形**：系统桌面按圆形展示应用图标，原来的圆角方块会被 Launcher 蒙版横切；改为满幅圆形蓝底 + 书本线框内缩到安全区，「关于」页 logo 圆角同步为 28px。

## 五、冷启动与内存治理

- **协议栈移出启动路径**：`app.ux` 不再 import OTP / 二维码协议栈，启动只保留约 4KB 的 `pushInbox` 薄缓冲层；手机推送按 `app` 字段分流暂存，用户进入动态口令 / 快捷生码相关页时桥接层认领并原样回放，落库与回执照旧。
  - band10 模拟器：`app.jsc` 51,520 → **23,867 B（−53.7%）**，协议栈求值段 38 → 29 ms，进程内首帧 295 → 289 ms。
  - 已知行为变化：插件侧「手环在线 · N 个账户」推迟到用户首次进入 OTP / 二维码页；歌词推送链路不受影响。
- **KV 单进程单次读盘**：`init()` 就绪后直接走内存，`reload(cb)` 作为显式重读逃生口；读盘返回时若已有未落盘改动，只合并未写过的键，避免启动早期「页面先写、读盘后到」冲掉新值；新增 `rev()` 供派生缓存失效。
- **互联层单例化**：状态统一挂 `globalThis.__bbIC`，同一 `connect` 实例只绑定一次 `onmessage` / `subscribe` / `onopen` / `onclose` / `onerror`；1006 断连重建同样只绑一次；`otpBridge.disarm()` 在 OTP 列表 / 同步页离页时退订状态监听，避免全局回调长期持有页面闭包。
- **OTP 每秒计算削减**：`otpStore.list()` 按 `g.kv.rev()` 缓存 normalized 列表；新增 `otpState.resolve()` 缓存同周期窗口的成功验证码（上限 64 条），列表与详情页每秒只重算剩余秒数；`otp.js` 保持与手机插件逐字一致。
- **文档仓库跨 bundle 缓存**：歌词本 / 笔记本的 `list` / `read` 按全局 `__bbDocsRev` 缓存，写操作成功即失效；歌词与笔记页面统一走 `docs.js` 写盘。
- **页面栈上限 6 层**：`router.push()` 探测栈深 ≥6 时降级为 `replace()`，防止异常深链长期驻留多份页面实例。
- **长亮与常驻对象**：桌面伴侣整分刷新；史载月份缓存改为容量 3 的 LRU；性能测试页测试链令牌化，离页 / 销毁立即取消递归定时器；推送分类先做协议字面量过滤再 `JSON.parse`。
- **新增门禁 R20（内存卫生）**：`@system.file` 只允许在 `utils/fs.js` / `utils/kv.js`，`@system.interconnect` 只允许在 `utils/interconnect.js`；含 `setInterval(` 的文件必须含 `clearInterval(`；歌词 / 笔记页面禁止直接调 `g.fs.writeText/remove/rename`。

## 六、滚动与布局修复

- **设置页 / 功能设置页**：卡片列表改为 `<scroll>` + 显式内容高，`CARD_COUNT` 与模板卡片数、`INNER_H` 与 CSS 常量三者对齐；卡片 `flex-shrink:0`，不再被 flex 压扁，最后几张设置卡也能滚到。
- **长文本页**：输入预览、摩斯电码、歌词、笔记正文等按字数估算折行高度并绑到内容容器，超出视口的部分滚得到。
- **新增门禁 R17（滚动内容高自洽）**：所有纵向 `<scroll>` 的直接子容器必须有显式高度；卡片列表页常量 / 卡片数 / 算式必须一致；profile 的文本宽度令牌与 CSS 一致。
- **页头与动作键**：页头整条是返回命中区（y0..74），保存 / 完成 / 参考 / 危险操作一律放页面底部；R15 扫描所有可点元素与页头矩形的交叠，重叠即拦下构建。

## 七、其它修复

- **答案之书接入全局摇一摇**：新增 `accelHub` 统一加速度计订阅（Vela 全局单槽、退订异步落定会误杀后续订阅），封面摇一摇翻开、答案页摇一摇再问一次；`motionShake` 含迟滞边沿、双甩配对、冷却与静默窗，就绪振不会自激成「再问」。
- **修掉就绪广播被自己的节流挡掉**：`announceReady` 的时间戳统一用秒，不再混用毫秒。
- **性能测试页**：离开页面立即清理递归测试链，不再在后台继续跑。
- **包体清理**：删除 4 张零引用 PNG（`more.png`、`switch_on.png`、`switch_off.png`、`blank.png`）。
- **长按管理边界**：隐藏项禁止再设收藏 / 置顶；首页收藏入口的数量即时刷新。

## 八、门禁与校验

- 静态门禁 `node tools/release-gate.mjs` 全过（**R1~R20**），含 PNG 完整性、埋点开关、`data`/`private` 不共存、路由与版本一致、profile 物化一致性、资源尺寸、计算器几何、包名规范、发行证书、AstroBox 清单引用、产物完整性、分类表完备性、页头命中区、滚动内容高、字号底线、内存卫生。
- 单测全部通过：`test-profile` **4934/4934**，另有 timezone / numinput / memory-fixes / otp-state / interconnect / docs-storage / companion-geo / cats / otp-cross 等 51 个测试文件。
- 三机型 profile 由 `profiles/band10.json`（基线）、`profiles/pro336.json`、`profiles/band9.json` 唯一决定；源码树保持 band10 基线态，物化只在构建瞬间发生并在退出时自动还原。
- 出包后逐包验签：签名完整性 + 包内版本号 + 包内包名 + 证书 CN 与 subject 7 项齐全，并核对 `SHA256SUMS.txt` 与磁盘产物逐字节一致。
