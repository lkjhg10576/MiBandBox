# BandBox 0.3.5 构建产物

构建时间：2026-11-06（本地）

- 手环端：`com.miband.box` **0.3.5**（`versionCode` 215，jsc 字节码版）
- 手机插件：`BandBox歌词同步` **0.2.5**（本版**代码未改动**，沿用 0.2.5 构建）

## 本版核心：四项体验问题修复

1. **红光手电首帧黑屏**
   根容器背景色此前只依赖动态内联插值 `style="background-color: {{ color }}"`，首帧该值未落到节点上就露出应用级黑底，
   而 `onShow` 里 `apply(0)` 赋的是与初值相同的颜色，不会触发二次 patch，于是「切一次颜色才恢复」。
   改为：`.page` 加静态红色兜底 + 5 个写死颜色的静态色层按 `index` 条件渲染（`fill0`~`fill4`），
   前景色同样静态化（`.fgLight` / `.fgDark`），首帧颜色不再依赖任何动态 style。

2. **手速测试结束后误触重开**
   原来整屏 `.tapZone` 绑 `@click="onTap"`，`onTap` 在 `idle`/`done` 时直接 `start()`，结算后随手一点就重开。
   改为：计数区与启动按钮拆开——按钮是 `.tapZone` 的**兄弟节点**（互不为父节点，不会冒泡触发计数），
   只在 `idle`/`done` 出现；`onTap` 只在 `running` 计数；`start()` 加重入守卫，连点按钮只产生一个倒计时；
   `clearTimers()` 顺带把状态复位，避免测试中切后台回来卡在 `countdown`。

3. ~~**水平仪方向相反**~~ — **本版不改**：真机与手机水平仪对比后确认，
   水平仪行为正常，只是小球的指示策略与「气泡指高侧」的直觉不同，不是缺陷，
   因此 `src/pages/level/level.ux` 保持原样。

4. **跑马灯横屏不生效、竖屏不滚动**
   - 模式真源从 KV 换成 `globalThis` 上的 `marqueeState`（新增 `src/utils/marqueeState.js`）：
     KV 读写异步、且 `marqueeMode` 残留会一直覆盖后续入口；KV 现在只负责「记住上次配置」。
   - 竖屏改为真正的横向滚动：`<scroll scroll-x>` + 4 个等宽内容块，`scrollBy` 按像素步进，
     走满一个周期整块回退一个周期宽，画面与周期边界一致 → 无缝循环。
   - 横屏复用歌词页已验证的旋转容器（`transform-origin:0 0` + `left:212px` + `rotate(90deg)`），
     整块内容旋转 90° 铺满 212×520，横竖两条路径共用同一套滚动后端。
   - 字号 24/30/38、速度 3/6/12、文字与背景色在两条路径上都生效。

5. **史载今日内容太少**
   - 数据从 90 条扩到全年 366 天、共 **414 条**史实（每天 ≥1 条，28 个重点日期 2~3 条），
     条目改为 `{ year, title, text, tag }` 数组结构，每条正文 ≥20 字且含年份；
   - 小知识池从 12 条扩到 **205 条**，`tipOfDay(m, d)` 按日期稳定散列返回**两条不同**的小知识；
   - 页面从「一句事件 + 空态提示」改成可滚动的多条列表（`scroll` + `for`），
     每天至少 2 条可读内容，空态文案改为「今日小知识」；
   - 新增 `node tools/test-history.mjs` 校验数据契约（366 键 / 合法日期 / 正文长度 / 去重 / 池子大小）。

## 兼容性说明（本渲染器实测 / 官方文档）

- **根容器的动态背景色在首帧可能不生效**：涉及整屏底色的页面一律加静态兜底色 + 条件渲染的静态色层，
  不要只靠 `style="background-color: {{ x }}"`。
- **`<scroll>` 的直接子元素是 div 时会参与 flex 收缩**：横向滚动的内容块必须显式写 `flex-shrink: 0`，
  否则被压扁到容器宽度，横向滚动直接失效。
- **`transform: rotate` 容器**：必须 `transform-origin: 0 0` 且 `left` 放在长边一侧（212px / 520px 那一组），
  绕中心旋转会向左溢出被 `.page { overflow: hidden }` 裁掉 → 整块不渲染。
- **Vela 的 `flex-direction` 默认是 `row`**（不是 CSS 标准的 column）；`align-items` 默认 `flex-start`。
- **`<text>` 默认字号 30px、默认颜色 `rgba(0,0,0,0.54)`**：动态 `font-size` / `color` 首帧未生效时要留静态兜底。
- **跨页传值不要走 KV**：KV 读写均为异步，播放页可能读到落盘前的旧值；用 `globalThis` 同步传值，
  KV 只用于持久化（见 `src/pages/fluorescence/fluoroState.js` 的既有做法）。
- `scroll` + `for` 里 class 三元绑定与 `$index` 仍不可靠（0.3.4 已记录）；条目字段用 `$item.xxx` 读取。
