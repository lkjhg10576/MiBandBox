## 本次更新

- **输入迁移到系统输入法**：全部输入场景改用 Vela 原生 `<input>` / `<textarea>`，
  获得焦点时由系统输入法接管（支持中英文，取决于固件 IME），不再内置英文自绘键盘。
  新增 `utils/textInput.js` 统一取值、换行归一、长度裁剪与摩斯字符过滤；
  `pages/input` 改为原生文本编辑页，进入后自动聚焦。涉及 9 个输入页面。
- **移除内置字体**：删除 BandBoxSans 字体子集与生成脚本，全部使用系统字体
  （Band 10/11 的 MiSans / MiLan Pro），rpk 体积约 811 KB → 388 KB。
- **修复页面可被左右滑动、抢占右滑返回手势的问题**：
  - 全局兜底：`.page` 增加 `overflow: hidden`（`theme.css` + 4 个全屏页），
    任何超宽子元素都不再撑出横向可拖动区域；
  - 逐页消除溢出：垃圾分类快捷词 chips（4×62 → 4×46）、参考分数「当前设备」行
    （机型名改弹性宽度 + 省略）、随机数行宽收紧与结果单行省略、
    记分牌 ≥1000 分自动缩小字号、数字滚动/木鱼/手速测试/剩余时间大数字加单行省略；
  - 计算器表达式框 `scroll-x`、跑马灯、密码长度滑块、歌词横屏等「设计内横向滚动」保持不变。
- 单测：手环端协议 25 项、日历 10 项、输入工具全部通过；插件端 61 项全部通过。

## 手环端安装

```bash
# 模拟器（需先启动 Vela 模拟器）
adb push com.miband.box.debug.0.2.1.rpk /data/app/com.miband.box.rpk
adb shell pm install /data/app/com.miband.box.rpk
adb shell am start com.miband.box
```

真机：把 `.rpk` 交给常用的快应用安装器 / AstroBox 安装即可。

## AstroBox 插件安装

把 `BandBox歌词同步.abp` 传到手机，在 AstroBox 里安装/导入该插件。
要求宿主支持 **API Level 4**（`wasi_version: 3`）。

使用流程：

1. 手环打开 BandBox →「歌词本」→「从手机传输」，停在该页面
2. 手机 AstroBox 打开「BandBox歌词同步」→ 选择 `.lrc` 文件
3. 点「发送到手环」，手环提示「已接收：<歌名>」后即可在歌词本中看到
