2. 荧光棒改为整屏单色循环，进入即最亮 + 常亮，退出恢复（新增公共工具 `utils/screen.js`）
3. 每日一言扩到 **1000 条**（见下）
4. 密码页：修复卡片双倍下移大片空白；密码两行完整显示；tab 改名「收藏夹」；收藏后自动切换
5. 振动器：脉冲间隔选中项改为实色蓝底 + ✓ + 边框，新增「当前间隔」提示，选择补振动
6. 剩余时间新增 本分钟 / 本小时 / 今天 / 本周 四档（`utils/time.js` 补 3 个倒计时函数 + 单测 10/10）
7. 木鱼重做：自绘暖木色木鱼 PNG（`tools/gen-assets/gen.py` 生成，无木槌）、今日 / 累计功德（旧 `fishMerit` 自动迁移）、功德 +1 上浮动画、自动敲击（关/慢/中/快三档，默认中速 800ms）、保留二次确认归零

9. 红光手电进入即最亮红光 + 常亮（改用 `utils/screen.js`）
10. 手速测试延长到 5 秒（`DURATION=5000`，提示与描述同步）
11. 数字滚动独立入口加入首页应用列表（补自绘图标 `num.png`），随机数页右上角入口移除
12. 性能分 = 132 × 基准总耗时 / 实测总耗时（相对基准分，Band 10 约 132 分；0.3.2 已落地）
13. 跑马灯改「竖屏播放 / 横屏播放」双入口，删除「全屏播放」卡片与重复按钮
14. 设置页删除「数据与隐私」卡片，版本号改为 0.3.3
15. 目标日日期选择器两步化（先选年 → 下一步 → 选月/日 → ✓ 完成）；日期回传改为全局临时状态（`pickState.js`），不再走 KV 的 pickDate；保存仍校验日期
16. 单栏首页列表项横向 margin 清零、列表容器加左右 padding，右滑返回不再被横向拖动抢占
17. 水平仪重做：双轴 roll/pitch、十字准星 + 中心目标圈、小圆点按倾斜方向偏移、角度读数、两轴校准归零

### 每日一言 1000 条

- 原创 100 条全保留；hitokoto 一言社区语句库 sentences-bundle（**AGPL-3.0**）筛选 + uapis.cn 随机一言接口抓取，合计筛出 900 条
- 四轮关键词过滤（负向词黑名单 + 强正向词门槛），去重后 1000 条，单条 5–28 字
- **随机策略**：进入 / 换一条改为持久化洗牌队列（1000 条一轮内不重样），替代原「按日期取模」
- 许可说明：quotes.js 引入 AGPL-3.0 语料，本项目整体开源发布于 AtomGit，与该许可兼容

### 已知限制（模拟器实测，真机待验证）

- Vela 模拟器渲染器：`transform: rotate()` 容器、canvas、`scroller` + `for` 组合均不可靠，路由参数绑定偶发丢失；跑马灯「横屏播放」因此降级为**特大字号逐字步进滚动**（纯 text 元素实现），90° 旋转待真机验证后启用
- marquee 组件字号在该渲染器上不可调（内联与 class 均被忽略），竖屏滚动字号固定
