构建时间：2026-11-21（本地）

- 手环端：`com.lkjhg.bandbox` **0.1.2**（`versionCode` 279，jsc 字节码版）
- 手机插件：`BandBox辅助` **0.1.2**（源码现编，与仓库源码一致）

> **production 打包**：由 `aiot release` 构建 —— JS 已压缩混淆、已剔除 `.map`、签名用发行证书。包名始终是 `com.lkjhg.bandbox`，文件名里的 `.release.` 段只表示打包模式，不是 debug 包。

>
> 手环端快应用与手机插件同号（均为 `0.1.2`）。本版是 **production 打包**（JS 压缩混淆、剔除 `.map`、自签发行证书签名），可对外分发。

## 〇、体感内核重构：就绪判定改绝对姿态

改前：进页面时采一份「垂手基线」，当前重力方向相对基线转过阈值才算就绪。问题有三个 —— 举枪与手平放都是转 90°，两者都能过阈值（平放会误就绪）；基线在未就绪时以 1.5s 时间常数跟着当前姿态跑，投完一球手臂放下 → 参考系整个变了；进页面必须先垂手才有基准。

改后：姿态由「重力落在哪个轴」唯一确定 —— 平放（重力沿屏幕法线 z）一律不就绪，没有会漂移的参考系，进页面不用先垂手。

- 轴 ↔ 姿态的映射集中在 `motionGun.POSE` / `motionHoop.POSE` 两个常量里，真机实测不符时只改这两处，判定数学不动。
- 判定用重力在目标轴上的**分量**而不是 `atan2` 角度：屏幕朝下时 `atan2` 会绕到 ±180°，会假越限。
- 灵敏度三档（低/中/高）同步改口径：从「举手角度门槛」变成「姿态偏离角门槛」，档位越高姿态越标准、触发所需幅度越小。

- **小米手环 11 纳入口径**：手环 11 固件严格执行「带 `if` / `show` 的包装 div 必须有完整几何 CSS 类」，否则里面的绝对定位子元素不会被布局（这就是「手环 11 点输入框只出完成栏、按键区全空」的根因）。`InputMethod` 的 `kbOuter` / `kbInner` / `kbBody` / `kbDown` 四个包装层已补齐 `position` + `left/top` + `width/height`，根容器高度写死 365px。

## 二、本版新增的工具

- **魔方计时**：体感计时带，对标 Stackmat 速拧计时。
  - 点「准备」后手平放（屏幕朝上）待命 → 翻腕起表 → 再平放收表，毫秒精度；
  - 起表与收表各长振一次，准备时短振一次；
  - 上滑查看最近 5 次成绩与最近 30 次平均，成绩本地留存；
  - 触发内核 `src/utils/cubeMotion.js` 与成绩存档 `src/utils/cubeStats.js` 均为零 `@system.*` 依赖的纯 JS，Node 可直接单测。
- **桌面伴侣**：横屏时钟 + 十档亮度 / 常亮。
  - `clock.ux` 把秒并入时间行（`HH:MM:SS` 同行同字号、8 个定宽格，消除每秒横向抖动），下排放闪电图标 + 电量百分比（新增 `@system.battery` feature，取值失败整组不渲染）。
  - **按机型自适应双版式**：跑道屏（466×212）两列整体放大（时间/几号 62→73、周几 41→45），矩形屏（466×336）改成「日期行 + 大时间」（上排几号/周几/电量，下排整行 `HH:MM:SS` 63→98px）；数字格字宽系数按实测墨迹收紧（数字 0.60em、冒号 0.36em）。
  - 设置页新增「**显示秒钟**」开关（KV `companionCfg.sec`）：关闭后隐藏 3 个秒格，时间行变窄仍居中。
  - 亮度档位与常亮选择改动即落盘，不再只靠「开始」保存。
- **快捷色卡**：HEX / RGB 输入 + 全屏看色。
- **单位换算新增第 13 类「进制转换」**：2 / 8 / 10 / 16 同屏互转。
- **二维码「从手机导入」**：手机插件粘贴文本发到手环，直接生成二维码。

## 三、首页新形态

- **「工具分类」显示模式**（设置页独立开关卡）：首页改为单栏显示 **9 个工具类别**，点进类别再单栏显示该类工具（两次点击直达）；关闭则回到上次记住的网格 / 列表样式。
  - 分类成员关系的唯一真源是 `src/data/cats.js`；`apps.js` 一律不加 `cat` 字段（它的数组顺序是模拟器脚本的导航依据）。
  - 分类模式复用既有的 grid/list 状态机（`'grid' | 'list' | 'cat'` 三态 + 模块闭包 + KV `'home'` 键 + `layout.txt` 启动快标志），另加 KV 键 `'homeStyle'` 记住上次的非分类样式。
- **「目标日不常驻」开关卡**（KV `'todayAuto'`，默认关 = 现状）：打开后只有设定了目标日才显示卡片，没设目标日时卡片不渲染，空出的空间全部给下方工具列表。

## 四、包体瘦身与统一数字键盘页

- **分级 A（9 页文本输入迁通用输入页 `pages/input`）**：笔记本编辑 / 歌词编辑 / 笔记本改名 / 目标日编辑 / 跑马灯 / 二维码 / 二维码 WiFi / 垃圾分类 / 摩斯电码（计划里漏列的第 14 个输入法页）。每页 `.jsc` 由 39~44 KB 降到 10~16 KB；从输入页返回不再被 KV / 文件重载或 `protected` 参数冲掉（统一加 `loaded` 守卫）。
- **分级 B（3 页原位数字控件，0 外跳 0 路由栈开销）**：节拍器 BPM 改卡内 ±1 / ±5 步进（运行中 restartTimer 不停节拍与常亮）、随机数改自绘小键盘、密码长度改走统一键盘页。
- **分级 C（3 个二级菜单页并进父页）**：笔记本「更多」/ 歌词「更多」/ 二维码「收藏详情」并入父页，互斥 `if` 切视图，规避 Vela 4 动态节点沉层。
- **全局样式**：`theme.css` 删掉零引用的 `.kbBar` / `.kbBarT` / `.header` / `.cardSub`（80 页 × 规则字节收益）。
- **包体**：dev 页面字节码 1,563,879 → 1,175,560 B（**−388 KB**）；生产包 929,828 → 790,454 B（**−139 KB**）。
- **新增统一数字键盘页 `pages/numinput`**：全屏自绘数字键盘，取代「页面内挂 `<input-method>`」——内置输入法贴快应用画布底摆放，弹出来正文整块被盖住，只剩 y76..100 一条缝；统一键盘页是**整页**，调用方的正文完全不受影响。
  - 接入方：随机数上下限、单位换算数值、密码长度（8~99 位）。
  - 回传走**两条通道**：`numInputSession`（内存快通道，零延迟）+ `inputResult`（一次性文件，异步兜底），调用方 `onShow` 先取内存、再取文件，两条都走 —— 只靠内存在跨 bundle 缓存不可见时会丢结果，只靠文件则有一次可见延迟。
  - 定长字段**传空串**而不是当前值：预填当前值会把用户卡死（草稿满 `maxLen` 后按任何数字都只会被「已达最大长度限制」挡回来，想从 16 改成 20 得先退格两次）。当前值改放进提示行 `hint`。

## 五、密码页改造

- 撤掉页内 `<input-method>` 与整套 `kbShow` / `lenDraft` 状态，正文不再随键盘态隐藏或上移。
- 长度行（页级 y230）点一下跳 `pages/numinput`（`field: 'pwdLen'`，8~99 位整数），返回后写回长度并按新长度重新生成。
- 弹键盘后正文下半段被盖住的问题彻底消失 —— 长度输入现在是**另一个整页**，密码页内容全程可见。

## 六、本版修复

- **就绪振不再误触发开枪 / 投篮**：就绪提示振会驱动马达，马达自身的振动被同一颗加速度计采到 —— 不挡掉的话，就绪振期间的那记尖峰会直接开枪（弹匣凭空少一格）。现在收到就绪事件后开一段静默窗口（就绪振 + 300ms 余量），并且就绪锁存的那一帧不响应触发。
- **就绪振改为按 200ms 节奏重叠重触发**：原先是三记紧挨着的长振，听感偏断续；现在 5 记覆盖约 1s，马达没停就重新起振，听感连续。`haptic.ready()` 现在返回提示振时长，页面用它设静默窗口。
- **投篮就绪姿态只认负 Roll**：真机实测手朝上 Roll ≈ −90，原 +x 映射装反。
- **页面动作键下沉到页面底部**：页头整条是返回命中区（y0..74），页头里放任何别的可点元素都会被吞掉。保存 / 完成 / 参考 / 危险操作一律放页面底部，主操作在上、次要与危险操作在最底。
- **消除原生 list 横向拖动空间**：原生 list 会把子项 margin 计入可横向滚动范围（3px 边距即产生可拖动空间，抢占右滑返回手势），改为 list 自身 padding 内缩。
- **进制转换草稿改存模块闭包**：输入不再退化成「一键覆盖一键」。
- **质感细节**：桌面伴侣秒位并入时间行后不再每秒横向抖动。
