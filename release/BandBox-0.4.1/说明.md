# BandBox 0.4.1 构建产物

构建时间：2026-11-07（本地）

- 手环端：`com.miband.box` **0.4.1**（`versionCode` 218，jsc 字节码版）
- 手机插件：`BandBox辅助` **0.3.1**（源码现编，与仓库源码一致）

> **0.4.0 装上去就会把系统搞进 Recovery，请勿使用。** 本版修的是真凶：
> 包内 47 张 PNG 缺 `IEND`，是截断文件。

## 真凶：47 张 PNG 缺 IEND

0.4.0 的图片瘦身用 `tools/pnglib.mjs` 把 102 张图转成 PNG8，而它的 `assemble()`
只拼 `IHDR / PLTE / tRNS / IDAT`，**从来没有写 IEND**。PNG 规范里 IEND 必须是最后一块，
没有它，文件在解码器看来就是被截断的。

改成 PNG8 的 47 张图里，包括应用图标 `common/icon.png`：

```
0.3.6（正常）  … 00 00 00 00 49 45 4e 44 ae 42 60 82   ← IEND
0.4.0（故障）  … 8e 1c 39 72 64 9d fe 07 3c ad 49 c5   ← 直接没了
```

系统在开机时要枚举应用、解码图标去画应用列表。手环侧的 PNG 解码器遇到没有 IEND 的文件，
会一直找下一块——读到文件尾之后是越界读或者死循环，结果是**系统界面起不来**。
连续几次启动失败，bootloader 把设备放进 Recovery，报「系统异常」。
恢复出厂设置把应用和数据清掉，图标不再被解码，于是又能开机——这和你看到的现象完全对得上，
也解释了为什么根本不是「点进去用某个页面」才出问题。

模拟器上看不出这个故障，因为它的解码器对缺失 IEND 是宽容的（读完 IDAT 就收工）。
这也是它一直没被 `npm run build` 发现的原因。

### 修复

1. `tools/pnglib.mjs` 的 `assemble()` 补 IEND（顺带保证它是最后一块）；
2. `tools/png-fix-iend.mjs` 给已有 47 张图就地补 12 字节
   （`00 00 00 00` + `IEND` + `AE 42 60 82`），不动像素、不重新量化；
3. `tools/release-gate.mjs` 新增 **R1 PNG 完整性**：签名、每块 CRC、chunk 是否越界、
   IEND 是否为末块、PLTE/tRNS 是否在 IDAT 之前。规则就是照着这次事故写的，
   已用「把一张图的 IEND 切掉」复现过它能拦住。

验证：包内 51 张 PNG 逐块 CRC + IEND 全部通过；`common/icon.png` 尾部恢复成
`49454e44ae426082`。

## 门禁规则（`node tools/release-gate.mjs`）

- **R1 PNG 完整性**：签名 / CRC / chunk 越界 / IEND 末块 / PLTE·tRNS 顺序
- R2 `perf.js` 的 `ENABLED` 必须为 `false`，`app.ux` 不得 import 埋点
- R3 启动路径（`home.ux`）不得出现 `getBoundingClientRect` 打点
- R4 页面对象不得同时含 `data` 与 `private`（Vela 直接抛错黑屏）
- R5 `router.pages` 每个路由必须有页面文件，`entry` 必须存在
- R6 `manifest.versionName` 与 `package.json.version` 一致

`build` / `build:jsc` 的 `pre*` 钩子与 `make-release.sh` 都会先过这道门。

## 安装

```
adb push com.miband.box.debug.0.4.1.rpk /data/app/com.miband.box.rpk
adb shell pm install /data/app/com.miband.box.rpk
adb shell am start com.miband.box
```

`pm install` 是异步的（模拟器约 1–2 分钟），装完再 `am start`，否则会黑屏（AMS 残留状态）。

## 已经进 Recovery 的手环怎么救

1. 手环放充电器上，长按侧键强制重启，多半会回到 Recovery；
2. 用手机 MI Fitness / 小米运动健康「移除设备」后重新配对；
3. 仍在 Recovery 就用 Mi Fitness 的「恢复出厂设置」——本次故障恢复出厂即可恢复，
   不需要刷机；
4. 恢复后**不要**再装 0.4.0，直接装本版。
