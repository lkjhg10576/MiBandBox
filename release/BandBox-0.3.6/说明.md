# BandBox 0.3.6 构建产物

构建时间：2026-11-06（本地）

- 手环端：`com.miband.box` **0.3.6**（`versionCode` 216，jsc 字节码版）
- 手机插件：`BandBox歌词同步` **0.2.5**（本版**代码未改动**，沿用 0.2.5 构建）

## 本版核心：三项体验修复与优化

1. **屏幕亮度恢复策略优化（荧光棒 / 红光手电）**
   - 进入前为系统自动亮度（`mode === 1`）时，退出页面只恢复自动模式，切勿调用 `setValue`（因为自动模式下系统常返回伪 0 值，会导致屏幕瞬间跌落最暗再拉回）；
   - 进入前为手动亮度（`mode === 0`）时，退出时恢复保存的手动亮度值与手动模式；
   - 增加快速进出竞态保护：防止用户迅速退出时 `getMode` 回调尚未返回，待回调到达时自动补做状态恢复；
   - 新增 `node tools/test-screen.mjs` 覆盖 5 种进出亮度与模式场景。

2. **史载今日列表滚动与排版防挤压**
   - 列表项与文字显式添加 `flex-shrink: 0`，标题加粗，优化行高与字号；
   - 列表增加动态内容高度估算 `estimateInnerHeight`，显式设定容器像素高度，解决 Vela flex 引擎偶发挤压条目的问题；
   - 滚动容器高度扩展至 300px，切换日期时通过 `scrollTo({ top: 0, left: 0, behavior: 'instant' })` 自动将列表滚动位置复位至顶部。

3. **跑马灯页面跳转提速与无缝滚动**
   - 移除跳转前等待 KV 异步落盘的回调等待，配置同步写入 `marqueeState.cfg` 后立即调用 `router.push`，KV 持久化转后台异步执行，消除点击「启动」时的卡顿与延迟感；
   - 播放页 `onShow` 显式调用 `startScroll()`，避免部分设备因 `onReady` 晚到导致的滚动顿挫；清理冗余状态声明。
