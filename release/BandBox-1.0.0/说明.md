## 本次修复

2026-11-01 重新构建了手机端插件，修复以下问题：

- `lifecycle` / `event` 必须是接口对象，且方法必须是 `async`；原来的顶层导出会被宿主调用时 trap，表现为「插件安装失败」
- QuickJS 运行时没有 `console` / `TextDecoder` / `setTimeout`，已改用纯 JS 解码与宿主 `timer` 接口
- `onLoad` 不再请求设备权限，安装阶段不会弹权限框

手环端 `.rpk` 未改动。

## 手环端安装

```bash
# 模拟器（需先启动 Vela 模拟器）
adb push com.miband.box.debug.1.0.0.rpk /data/app/com.miband.box.rpk
adb shell pm install /data/app/com.miband.box.rpk
adb shell am start com.miband.box
```

真机：把 `.rpk` 交给常用的快应用安装器 / AstroBox 安装即可。
包名 `com.miband.box`，版本 `1.0.0`（versionCode 10000），设备类型 `watch`。

> 这是开发签名包，用于模拟器与侧载验证；上架/正式分发需用自己的证书执行
> `aiot release` 重新签名。

## AstroBox 插件安装

把 `BandBox歌词同步.abp` 传到手机，在 AstroBox 里安装/导入该插件。
要求宿主支持 **API Level 4**（`wasi_version: 3`）。

使用流程：

1. 手环打开 BandBox →「歌词本」→「从手机传输」，停在该页面
2. 手机 AstroBox 打开「BandBox歌词同步」→ 选择 `.lrc` 文件
3. 点「发送到手环」，手环提示「已接收：<歌名>」后即可在歌词本中看到
