# BandBox 0.3.4 构建产物

构建时间：2026-11-05 01:26（本地）

- 手环端：`com.miband.box` **0.3.4**（`versionCode` 214，jsc 字节码版，54 个 .jsc）
- 手机插件：`BandBox歌词同步` **0.2.5**（本版**代码未改动**，沿用 0.2.5 构建）

## 本版核心：六项功能体验改进

1. **振动器**：脉冲间隔选择器由「✓ 前缀 + 描边胶囊」改为与振动策略一致的分段控件（选中实色蓝底），修复选中 500ms 时文字加长导致的意外换行
2. **剩余时间**：
   - 本周还剩改为「N 天（大字）+ HH:MM:SS（蓝字）」两行结构，修复天数较长时被截断成省略号
   - 「秒」「天」单位改为兄弟节点渲染，修复嵌套文本在本渲染器上不显示的问题
   - 全部五张卡片（本分钟 / 本小时 / 今天 / 本周 / 今年）均配进度条与「已过去 X%」提示，此前仅今天 / 今年有
3. **每日一言**：
   - 页面底部新增「我的收藏 (N)」入口
   - 新增收藏列表页（`pages/sentence/fav`）：展示全部收藏句子，点按一次进入确认态（卡片变红提示「再点一次删除」），再次点按确认删除，防误触；含空态引导
4. **水平仪**：进入页面即阻止自动熄屏（只常亮、不改亮度，离开恢复），读数不再中途熄屏
5. **荧光棒**：新增启动前配置页（变色速度 慢/中/快 三档、高亮屏幕 开/关、阻止熄屏 开/关），点「启动」进入播放页；配置经 KV 落盘传递并记住上次选择；`utils/screen.js` 扩展支持高亮与常亮两个开关独立组合，红光手电等既有调用零改动
6. **每日一言收藏数据结构不变**（`quoteFavs` 纯字符串数组，上限 50 条）

## 兼容性说明（本渲染器实测）

- scroll 容器 + `for` 循环中，class 属性的三元绑定与事件参数 `$index` 均不可靠：收藏卡片选中态改用内联 style 三元、删除定位改用 `$item` 文本值匹配
- `list` 组件的 list-item 需要确定高度，内容自然高度的条目不渲染；收藏列表改用 `scroll` + div 实现
- 嵌套 `<text>`（数字后内联小号单位）在本渲染器上不渲染，单位改为 flex 兄弟节点
