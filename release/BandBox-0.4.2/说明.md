# BandBox 0.4.2 构建产物

构建时间：2026-11-07（本地）

- 手环端：`com.miband.box` **0.4.2**（`versionCode` 219，jsc 字节码版）
- 手机插件：`BandBox辅助` **0.3.1**（源码现编，与仓库源码一致）

> 0.4.0 装上会进 Recovery、0.4.1 是那次事故的修复版。本版在 0.4.1 之上
> 恢复图标清晰度并新增一个功能，**0.4.1 的 IEND 修复全部保留**。

## 一、图标恢复清晰（0.4.0 的 PNG8 降级回滚）

0.4.0 为压包体把 102 张 PNG 转成 PNG8，工具链 `tools/pnglib.mjs` 自己做
「44×44 → 28×28 盒式重采样 + 256 色量化」。两个后果叠在一起：

1. **盒式重采样**丢掉抗锯齿边缘的过渡像素，只留下纯色笔画；
2. **256 色量化**在抗锯齿边缘撒彩色噪点，加上非预乘 alpha 平均把透明黑混进边缘。

真机上的表现是笔画发毛、细节糊成一团（0.4.1 只补了 IEND，没动像素，
所以这个现象在 0.4.1 上依然存在）。

本版把 **46 张图全部恢复成 `56b1dd1^` 的原始 RGBA 版本**：

| 类别 | 张数 | 说明 |
|---|---|---|
| 首页工具图标 | 30 | `common/icons/*.png`（另加 0.4.2 新增的 `dailytip.png`，共 31 张） |
| 应用图标 | 1 | `common/icon.png`，216×216 RGBA |
| 通用图 | 4 | `check.png` / `empty.png` / `plus.png` / `images/muyu.png` |
| 输入法按键 | 11 | `components/InputMethod/assets/arc/*.png` |

渲染器恢复与 0.3.x 相同的平滑缩放（列表 34px、网格 28px 都是缩小显示，实机清晰）。

**代价**：PNG 资源 51 张 / 41,714 B → **52 张 / 68,573 B**，
rpk 613,476 B → **648,685 B**（+35,209 B，+5.7%），相对 0.3.6 的 966,411 B 仍 −32.9%。
0.4.0 的性能主体（公共模块单例 / 全局时钟 / 数据外置 / 首页虚拟化）不受影响。

`tools/png8.mjs` 已加注释：**禁止**再对带抗锯齿边缘的 UI 小图跑 `--convert` / `--resize`。

## 二、新增「每日新知」

小知识原本只是「史载今日」里的兜底条目，混在史实后面、每天追加好几条，
读起来像史实又不像。现在独立成第 30 个工具 `pages/dailytip`：

- 语料：205 条科技小知识（`common/data/history/tips.txt`）；
- **每天固定一条**：按「月 × 日」稳定散列取下标，同一天每次进入都是同一条，跨天自动更换；
- **「换一条」只对本次有效**：临时换一条并把标题改为「随手一读」，
  离开再进入恢复当日那一条；
- 「史载今日」回归纯史实：只有当天确实没有史实条目时，才兜底显示一条小知识。

新增灯泡图标 `common/icons/dailytip.png`（44×44 RGBA，自绘）。

## 四、安装

```
adb push com.miband.box.debug.0.4.2.rpk /data/app/com.miband.box.rpk
adb shell pm install /data/app/com.miband.box.rpk
adb shell am start com.miband.box
```

`pm install` 是异步的（模拟器约 1–2 分钟），装完再 `am start`，否则会黑屏（AMS 残留状态）。
本版 `versionCode` 高于 0.4.1，可直接覆盖安装，不需要先卸载。
