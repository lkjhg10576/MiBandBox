# BandBox 0.4.0 构建产物

构建时间：2026-11-07（本地）

- 手环端：`com.miband.box` **0.4.0**（`versionCode` 217，jsc 字节码版）
- 手机插件：`BandBox歌词同步` **0.3.0**（本版**源码现编**，与仓库源码一致）

## 本版核心：性能重构（包体 −36.5%，首帧更早）

工具链把每个页面打成独立 bundle，公共模块原本在每个 bundle 里各有一份副本；
这既撑大包体，也让各页的内存缓存互不可见。本版把公共模块统一挂到全局单例上。

### 1. 公共模块全局单例化

- 新增 `src/global.js`：整个 App 只有一份 `kv / router / fs / time / haptic / screen / clock`；
  该文件**只在 `app.ux` 里 import**（模块顶层求值早于 `onCreate`，也早于任何页面创建）。
- 新增 `src/utils/g.js`：页面唯一可用的取用入口（shim）。
  用 shim 而不是直接解构 `global`：若某页 bundle 在 `g.__bb` 赋值前求值，
  直接解构会得到 `undefined` 并抛错白屏；shim 返回 `{}` 只会缺功能、不会崩页面。

| 指标 | 优化前 | 优化后 |
|---|---|---|
| rpk 大小 | 966,411 B | **613,577 B**（−36.5%） |
| bundle 原始总量 | 8,712,032 B | 4,618,834 B（−47%） |
| router / file / kv 模块副本 | 59 / 37 / 23 | **1 / 1 / 1** |
| 20s 时钟定时器 | 49 个 | **1 个**（无订阅时自动停） |
| PNG 资源 | 102 张 / 156,869 B | 51 张 / 41,714 B（PNG8） |

### 2. 全局时钟合并

- 新增 `src/utils/clock.js`：把 49 个页面各自的 20s 定时器合并成 1 个；
  页面订阅（`onShow`）时立刻拿到当前时间，之后每分钟变化时回调一次。
- 无人订阅时定时器自动停止 —— 「页面隐藏后时钟还在跑」从结构上不再可能。

### 3. 首帧优化：布局标志快路径

- 新增 `src/utils/layoutFlag.js`：启动时先读一份 4 字节的 `layout.txt` 判断首页用网格还是列表，
  不必等整份 `store.json` 读完并 `JSON.parse`；`kv.init()` 仍以 KV 里的值为准，
  两者不一致时以 KV 为准并通知页面刷新（避免网格闪现）。

### 4. 数据集外置为包内 .txt

- 史载数据改为按月拆分：`src/common/data/history/01.txt` ~ `12.txt` + `tips.txt`，
  覆盖 **366 天 / 414 条史实**，小知识 **205 条**；每日一言 **1000 条**（`quotes.txt`）。
- 数据从 JS 源码移到包内文本，
  页面侧用 `src/utils/historyPure.js` / `historyData.js` / `quotesData.js` 读取。
- 数据契约已校验：每天至少 1 条史实、正文 ≥20 字、同日不重复、跨年闰日等。

### 5. 资源瘦身

- 资源用内部工具链转成 PNG8：RGBA8 资源 102 → 5，>256 色资源 7 → 0。
- 输入法定制：删除 `full/`、`horizontal/`、`t9/` 三套重复按键图与日文相关资源，只留 `arc/` 一套。

### 6. 性能埋点

- `src/utils/perf.js`：跨 bundle 共享的埋点表（存在 `global` 上，否则各 bundle 各有一份）。

### 7. 发行打包方式调整

- 手机插件改为**从源码现编**后再打包。旧做法是从上一版发行目录拷旧 `.abp`，
  插件源码一变（如 0.3.0 的动态口令同步）就会漏掉新功能，且旧目录一旦清理就没得拷。
- 仓库只保留最新一版发行版目录，旧的已清理。

## 兼容性

- 数据格式与上一版（0.3.6）不兼容的部分仅限包内布局；用户侧 KV / 笔记 / 口令账户等本地数据保持不变。
- 手机插件 0.3.0 支持把 `otpauth://` 账户批量导入并与手环双向同步，
  需要手环端同为本版（0.4.0）及以上；旧手环端仍可只使用歌词推送功能。

### 校验

见 `SHA256SUMS.txt`。安装：`adb push` 后 `pm install`，或用 AIoT-IDE 安装 jsc 包；
普通 JS 包（`npm run build`）仅用于模拟器调试。
