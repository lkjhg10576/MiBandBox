## 本版更新（内存泄漏缓解与高频调用削减）

### P0 — 确定性修复与高频调用削减
- **性能测试页**：`runTimer` + `runSeq` 令牌化，离开页面（`onHide` / `onDestroy`）立即 `cancelRun()` 清理递归链；删去未用的 `data.timer`。
- **KV 单次读盘**：移除 5 秒窗口重读，`init()` 就绪后直接复用内存；新增 `reload(cb)` 强制重读逃生口与 `rev()` 版本号；读盘返回若存在未落盘改动，仅合并未写过的键，避免覆盖早期写入。
- **互联层单例化**：新增 `interconnectCore.js` 并将连接状态集中到 `globalThis.__bbIC`，同实例只绑定一次 `onmessage` / `subscribe` / `onopen` / `onclose` / `onerror`，1006 断连重建同样只绑一次；`otpBridge` 新增 `disarm()` 并在 `otp/list`、`otp/sync` 离页时退订状态监听。
- **文档仓库缓存**：`docs.js` 维护全局 `__bbDocsRev`，`list`/`read` 跨页面缓存复用，`save`/`remove`/`rename` 成功后递增失效。
- **OTP 每秒计算削减**：`otpStore.list()` 按 `g.kv.rev()` 缓存 normalized 列表；新增 `otpState.resolve()` 缓存同周期窗口验证码（上限 64 条），每秒仅重算倒计时；`otp.js` 保持零改动。
- **页面栈深度上限**：`router.push()` 在 `getLength() >= 6` 时降级为 `replace()`，挡住异常深链多实例驻留。
- **推送前置过滤**：`pushInbox.classify()` 先按 `"bandbox-otp"` / `"bandbox-qr"` 字面量过滤，不再对歌词或其它消息执行 `JSON.parse`。

### P1 — 长亮页、常驻缓存与包体清理
- **桌面伴侣时钟**：精美样式与关秒模式切换为整分 +20ms 对齐的 `minuteTimer`（60 次/小时，不再每秒重绘）。
- **史载今日**：月份缓存改为容量 3 的 LRU，控制跨月浏览后的常驻内存。
- **包体清理**：删除 4 张零引用 PNG（`more.png`、`switch_on.png`、`switch_off.png`、`blank.png`）及误打包的 `src/common/images/.mimosa/`。

### P2 — 门禁与验证
- 新增门禁 **R20（内存卫生）**，约束 `@system.file` / `@system.interconnect` 入口、`setInterval`/`clearInterval` 配对及歌词/笔记写盘出口。

## 安装

```bash
adb push <上表对应机型的 rpk> /data/app/com.lkjhg.bandbox.rpk
adb shell pm install /data/app/com.lkjhg.bandbox.rpk
adb shell am start com.lkjhg.bandbox
```

本版 `versionCode` 为 294，可在模拟器或手环真机上直接覆盖安装（`pm install`），本地数据完整保留。
