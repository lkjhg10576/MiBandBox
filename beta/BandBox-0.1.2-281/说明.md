## 本版改动

**1. 桌面应用图标改圆形**（修「方形图标与系统圆形图标割裂」）

手环系统桌面按圆形展示应用图标，原来用的是圆角方块（`src/common/icon.png`），在桌面上显得方、且会被 Launcher 的圆形蒙版横切。现改为**满幅圆形蓝底 + 书本线框内缩到安全区**（216×216，四角透明）：

- 形状真源在 `tools/gen-assets/gen_8pro_icon.py`（8 Pro 桌面圆形蒙版诊断的结论，见 `docs/8pro-diag.md`）——**根因是形状不是尺寸**，改成圆底后蒙版怎么套都是圆的；
- 应用内「关于」页的 logo 圆角同步改成 28px（= 56px 盒子的半边），保证完整圆形不被切角；
- 应用内的 40 个工具图标维持线描 glyph 现状，未改。

**2. 冷启动减负**（修「点进快应用启动慢」）

启动时引擎要加载并求值 `app.jsc`，原来整条 OTP / 二维码协议栈（otpProtocol / otp / otpAccounts / otpStore / qrProtocol / qrFavStore，约 68KB 源码）都在这条路径上，哪怕用户只想看个计算器。现改为：

- 启动路径只留一份约 4KB 的薄缓冲层 `pushInbox`：手机推送先按协议分流存着；
- 用户进入「动态口令」或「快捷生码」相关页时，对应接收层认领并**原样回放**缓冲 → 落库与回执照旧，**推送数据不丢**；
- 实测（band10 模拟器，冷启动分段）：`app.jsc` **51,520 B → 23,867 B（−53.7%）**，协议栈求值段 38ms → 29ms，进程内首帧总耗时 295ms → 289ms。

**已知行为变化**：手机插件侧「手环在线 · N 个账户」的显示**推迟到用户首次进入动态口令 / 快捷生码页**（此前是进入应用即显示）。歌词推送不受影响（歌词页自带就绪广播）。

> 真机 CPU 远慢于模拟器，协议栈从启动路径移走与 `app.jsc` 减半的收益在真机上应更明显 —— 请重点体验「从桌面点进 BandBox」到首页出现这一段的快慢。

## 安装

```bash
adb push <上表对应机型的 rpk> /data/app/com.lkjhg.bandbox.rpk
adb shell pm install /data/app/com.lkjhg.bandbox.rpk
adb shell am start com.lkjhg.bandbox
```

本版 `versionCode` 为 281，可在模拟器或手环真机上直接覆盖安装（`pm install`），本地数据完整保留。
