## 安装

```bash
adb push <上表对应机型的 rpk> /data/app/com.miband.bandbox.rpk
adb shell pm install /data/app/com.miband.bandbox.rpk
adb shell am start com.miband.bandbox
```

本版 `versionCode` 为 235，可在模拟器或手环真机上直接覆盖安装（`pm install`），本地数据完整保留。
